# ⚠️ DEPRECATED

**This component has been replaced by [MoltlerHub](../moltler-hub/).**

## What to Use Instead

MoltlerHub (`moltler-hub/`) is now the main web interface for Moltler. It provides:

- Interactive getting started experience
- Skills browser with search and filtering
- Documentation and agent connection guides
- Modern Next.js stack with static generation

## To Run MoltlerHub

```bash
cd moltler-hub
npm install
npm run dev
# Open http://localhost:3000
```

Or use quick-start:

```bash
./scripts/quick-start.sh --hub
```

## Why Deprecated?

- MoltlerHub provides a better user experience
- Focus on getting started and AI agent integration
- Static generation for deployment anywhere
- No need to maintain two separate UIs

This directory is kept for reference but will be removed in a future release.
